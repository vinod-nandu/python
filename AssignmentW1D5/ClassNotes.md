# LLMs: Open Source vs Closed Source

## 1. Open Source LLMs
- Model **files are freely available** for anyone to download and use.
- Can be run locally / self-hosted (no dependency on a company's server).
- **Examples / platforms:**
  - Ollama (tool to run LLMs locally)
  - Hugging Face (hub for downloading and sharing open-source models)

## 2. Closed Source LLMs
- Model itself is **not released** — you only get access through a service.
- Workflow: **LLM → Use (via API/App) → Pay**
- Access is usage-based (pay-per-use / subscription), since you're using the provider's infrastructure.
- **Major providers:**
  - OpenAI
  - Anthropic
  - Grok (xAI)
  - Google
- Access typically happens through an **API**, which can end up being **relatively expensive** for heavy/production use.

## Key Takeaway

| Aspect | Open Source | Closed Source |
|---|---|---|
| Access | Free, downloadable files | Paid, via API/platform |
| Hosting | Self-hosted (local/own servers) | Provider-hosted |
| Examples | Ollama, Hugging Face models | OpenAI, Anthropic, Grok, Google |
| Cost | Free (compute cost only) | Pay-per-use, can get costly |
