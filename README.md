# Python
## Learn Python in 10days


| Topic                | short def                                                                                                                  |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| **Python Operators** | Operators are symbols used to perform arithmetic, comparison, logical, assignment, and other operations on values.                    |
| **Data Types**       | Data types define the kind of value a variable can store, such as `int`, `float`, `str`, `bool`, and `None`.                          |
| **Lists**            | Lists are ordered and mutable collections that can store multiple values, including duplicates.                                       |
| **Sets**             | Sets are unordered collections of unique elements, useful for removing duplicates and performing set operations.                      |
| **Tuples**           | Tuples are ordered and immutable collections used to store values that should not be changed.                                         |
| **Dictionary**       | Dictionaries store data as **key-value pairs**, allowing fast access using unique keys.                                               |
| **Control Flow**     | Control flow determines the order in which Python statements are executed using conditions, loops, and branching.                     |
| **Nested `if`**      | A nested `if` is an `if` statement placed inside another `if` or conditional block to handle multiple levels of decisions.            |
| **Loops**            | Loops repeatedly execute a block of code using `for` or `while` until a specified condition is met.                                   |
| **Functions**        | Functions are reusable blocks of code designed to perform a specific task and can accept inputs and return outputs.                   |
| **Modules**          | Modules are Python files containing reusable code such as functions, classes, and variables that can be imported into other programs. |
| **Error Handling**   | Error handling uses `try`, `except`, `else`, and `finally` to detect and manage runtime errors without crashing the program.          |
